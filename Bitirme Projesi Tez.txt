SUMMARY
Nowadays, financial management has become increasingly difficult due to reasons such as the diversity of financial transactions and the use of multiple bank accounts. In this study, a personal finance application has been developed to support especially young users in maintaining an income-expense balance and to provide recommendations based on their spending habits. The application presents a financial summary to the user and visualizes this data graphically. Users can update their income-expense information and add new transactions. When an expense is added, categorization is performed through the "Transaction Categorization" artificial intelligence module based on the text entered in the description field. On the analysis screen, financial data is analyzed using a Machine Learning (ML) AI module, and the analyzed data is displayed graphically. Future spending predictions for the upcoming month are generated using a "Predictive Analytics" AI module, and personalized savings recommendations are provided to the user based on these forecasts. Through the Chatbot feature powered by Natural Language Processing (NLP), users are presented with pre-defined questions to obtain information about their personal financial status and receive customized savings advice.

The application is developed with a .NET Core (ASP.NET Core) based backend architecture and a React-based frontend interface. Microsoft SQL Server is utilized on the database side. To prevent security vulnerabilities, user data is stored in the database in an encrypted format.
Keywords: Personal Finance Management, Artificial Intelligence, Machine Learning, Transaction Categorization, Predictive Analytics, Natural Language Processing, .NET Core, React
